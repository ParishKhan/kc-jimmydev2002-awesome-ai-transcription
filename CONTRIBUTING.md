# Contribution Guidelines

Thank you for considering contributing to this list!

## Adding a new item

- Search previous suggestions before making a new one to avoid duplicates.
- Make an individual pull request for each suggestion.
- Use the following format: `[Name](link) - Description.`
- New items should be added to the bottom of the relevant category.
- Keep descriptions short, simple, and accurate.
- Start the description with a capital letter and end with a period.
- Check your spelling and grammar.
- Make sure your text editor is set to remove trailing whitespace.
- The pull request title should follow the format: `Add [Name]`.

## Updating an existing item

- If you notice outdated information, feel free to submit a PR with updates.
- Include a brief explanation of what changed and why in the PR description.

## Quality standards

To be included in the list, tools and resources should meet at least one of the following:

- Be actively maintained (updated within the last 12 months).
- Have significant adoption or community usage.
- Offer unique functionality not covered by existing entries.
- Open-source projects should have 50+ GitHub stars.

## Removing items

- If a tool is discontinued or no longer maintained, please submit a PR to remove it.
